## 直接ダウンロード＆簡単インストール（ターミナル不要）

1. **インストーラーをダウンロード**:
   - [**`MacCare-Universal.dmg` をダウンロード（推奨）**](https://github.com/lph2o/MacCare/releases/latest/download/MacCare-Universal.dmg)
   - [**`MacCare-Universal.zip` をダウンロード**](https://github.com/lph2o/MacCare/releases/latest/download/MacCare-Universal.zip)
2. **ドラッグ＆ドロップ**: `MacCare-Universal.dmg` を開き、**MacCare** を **アプリケーション（Applications）** フォルダにドラッグします。
3. **起動**: アプリ右上の地球アイコンからいつでも表示言語（**🇬🇧 EN, 🇫🇷 FR, 🇪🇸 ES, 🇩🇪 DE, 🇯🇵 JA, 🇨🇳 ZH**）を切り替えられます。
   > *初回起動時のヒント (macOS Gatekeeper)*: 初回起動時に警告が表示された場合は、**MacCareを右クリック（またはControl+クリック）→「開く」** を選択してください。
