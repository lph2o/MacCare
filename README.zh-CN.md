# MacCare

**开源原生 macOS 系统维护、APFS 存储空间分析、Mach 内核遥测与安全防护套件。**  
*基于 Swift、SwiftUI、AppKit、Swift Charts、SQLite3 与 CryptoKit 构建 — 原生支持 Intel (`x86_64`) 与 Apple Silicon (`arm64`) 通用二进制（支持 macOS 14 Sonoma 及更高版本）。*

## 直接下载与一键安装（无需任何命令行或编程知识）

1. **点击直接下载安装包**：
   - [**下载 `MacCare-Universal.dmg`（推荐 — macOS 磁盘映像）**](https://github.com/lph2o/MacCare/releases/latest/download/MacCare-Universal.dmg)
   - [**下载 `MacCare-Universal.zip`（即开即用压缩包）**](https://github.com/lph2o/MacCare/releases/latest/download/MacCare-Universal.zip)
2. **拖拽安装**：双击打开 `MacCare-Universal.dmg`，将 **MacCare** 拖入 **应用程序 (Applications)** 文件夹。
3. **打开应用**：您可以在应用右上角的地球图标中随时一键切换界面语言（**🇬🇧 EN, 🇫🇷 FR, 🇪🇸 ES, 🇩🇪 DE, 🇯🇵 JA, 🇨🇳 ZH**）。
   > *首次打开提示 (macOS Gatekeeper)*：首次启动开源应用时，若 macOS 弹出安全提示，请 **右键点击（或按住 Control 点击）MacCare → 打开**，再点击 **打开** 即可。
